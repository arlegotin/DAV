The default 7B setup experienced critical memory pressure and swap growth. That genuine resource limitation triggered the specified fallback before research collection. Format setup also exposed two adapter defects: the conversion's EOS differed from its tokenizer's declared chat EOS, and MLX's streaming display removed an initial space, corrupting Python indentation. The loader honors the pinned tokenizer EOS; output now decodes generated token IDs once with cleanup disabled. Every earlier output and cost is preserved.

The frozen wrapper includes a public format demonstration and a fixed assistant prefix (`def solve(x):` for proposals; an unfinished verdict JSON key for reviews). Prefix tokens count as input; the prefix supplies no verdict, no candidate solution, and no private information. Generated bytes remain unmodified. This restricts claims to the declared microtask interface. The last M1 byte-decoding fix followed the implementation review and has a regression test; it was not independently re-reviewed.
